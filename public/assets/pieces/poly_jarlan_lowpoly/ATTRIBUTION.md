# Low-Poly Chess Pieces — Jarlan Perez (via Poly Pizza)

- **Source:** https://poly.pizza/ (search "chess") — the six individual "Chess
  {Piece}" models by Jarlan Perez.
- **Author:** Jarlan Perez
- **License:** CC-BY (Creative Commons Attribution) — attribution **required**;
  recorded here and logged per episode in the manifest.
- **Files:** one GLB per piece type (`{pawn,knight,bishop,rook,queen,king}.glb`),
  each a single low-poly mesh, Y-up, single material.

Loaded by `src/synth/piece_models.ts` as a `per-type` set (one file per type;
recolored white/black at load, since the source material is a single dark tone).
